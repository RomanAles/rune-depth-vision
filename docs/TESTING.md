# Проверка проекта

## Автоматические проверки

```powershell
.\.venv\python.exe -B -m unittest discover -s tests -v
.\.venv\python.exe -m pip check
```

Тесты не используют реальную камеру и не скачивают веса. В тесте видео применяется
синтетический поток и подмена модели; отдельно выполнен ручной GPU-прогон настоящих моделей.
Временные тестовые файлы создаются внутри `.venv` и удаляются после проверки.

## Реальные измерения глубины

1. Устранить ошибку захвата камеры 2 и зафиксировать фактическое разрешение/бэкенд.
2. Откалибровать камеру для этого режима. Не использовать демонстрационные значения README.
3. Измерить высоту и наклон камеры, записать фокус и условия освещения.
4. Расположить объект на нескольких известных расстояниях в рабочем диапазоне.
5. Для центральной области сопоставлять осевую глубину Z с измеренным расстоянием вдоль оси камеры.
6. Снять несколько независимых кадров на каждом расстоянии; не считать соседние кадры независимыми сценами.
7. Записать истинную и оценённую дистанцию в CSV с колонками `true_m,estimated_m`.
8. Выполнить `evaluate.py` и сохранить параметры испытания вместе с отчётом.

Отдельно проверить фон внутри рамки YOLO, тонкие препятствия, контрастное освещение,
отсутствующую глубину и поверхность пола. Подготовить разметку ожидаемых состояний
STOP/SLOW/CLEAR/NO_DEPTH и посчитать пропуски и ложные тревоги.
Пороги приемлемой ошибки и задержки пока не утверждены.

## Длительный тест

После восстановления камеры запустить выбранный рабочий режим минимум на час.
Периодически фиксировать память процесса, FPS, p50/p95, загрузку GPU и потери кадров.
Отдельно проверить отключение камеры, занятое устройство, недоступный файл модели,
Ctrl+C, заполнение выходного диска и запуск из другой рабочей папки.

Нативный вызов драйвера DirectShow может блокироваться: try/finally обрабатывает исключения
Python, но не прерывает зависший вызов Windows. Это открытый дефект перед 1.0.
Не оставлять диагностические процессы с зависшим захватом без контроля.

## Текущие результаты

- 30 автоматических тестов: успешно.
- `pip check`: конфликтов нет.
- Настоящие YOLO и Depth Anything: совместный CUDA-прогон успешен на тестовом видео.
- Экспорт AVI/JSONL/NPY и повторное чтение выходного видео: успешно.
- Синтетические 60 кадров 640x360: total p50 30.85 мс, p95 41.65 мс, без окон и записи.
- Физическая камера 2: кадр не получен; DirectShow завис, MSMF отклонил открытие.
- Реальная точность, разметка сцен, часовой тест: не выполнены.
