# Требования к версии 1.0

Рабочая платформа: Windows, ARDOR GAMING RUNE, NVIDIA RTX 4070 SUPER (12 ГБ).
Камера по умолчанию: индекс 2. Это настройка пользователя, а не обнаружение по имени.
Предпочтительный захват: 1920x1080, 60 кадров/с, MJPEG; фактический режим проверяется при запуске.
Окружение: Miniconda, Python 3.11, локальная папка `.venv`, PyTorch с CUDA.

## Функции релиза

- Обнаружение объектов, оценка глубины и совместный режим.
- Источники: камера и записанное видео.
- Оценка состояния пути: STOP, SLOW, CLEAR, NO_DEPTH.
- Карта глубины и pseudo-LiDAR с калибровкой камеры.
- Конфигурация без изменения исходников, запись результатов, работа без окон.
- Воспроизводимые проверки и документация установки.

## Приёмка

- Установка в чистое окружение и запуск по README.
- Проверки аргументов, обработка потери камеры и освобождение ресурсов.
- Автоматические тесты геометрии, порогов, конфигурации и обработки видео.
- Час работы без падений и устойчивого роста памяти.
- На реальных сценах измеряются ошибка расстояния, пропуски, ложные тревоги и задержка p50/p95.

До получения контрольных измерений численные пороги точности и задержки не утверждены.
Рабочий диапазон расстояний и условия освещения также должны быть подтверждены испытаниями.
Синтетические тесты не заменяют эти измерения.
